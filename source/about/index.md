## 你好 👋

我是 **OQ711**，这里是我的个人博客。

用来记录学习过程中的笔记、折腾工具时踩的坑，以及一些零零散散的想法。
写下来主要是为了对抗遗忘——毕竟「当时明明搞懂了」和「现在还能讲清楚」是两件事。

## 关于这个站

| 项目 | 说明 |
| --- | --- |
| 框架 | [Hexo](https://hexo.io/zh-cn/) 8 |
| 主题 | [Butterfly](https://butterfly.js.org/) 5 |
| 托管 | GitHub Pages（[源码仓库](https://github.com/oq711/blog)） |
| 写作 | Markdown + Git，push 即发布 |

整个站点是纯静态的，没有数据库、没有服务器。写完文章 `git push`，GitHub Actions 自动构建并部署，一分钟左右上线。

## 我在这里写什么

- **学习笔记**：正在学的东西，尽量写到能复现的程度
- **工具折腾**：环境配置、脚本、效率工具
- **踩坑记录**：报错和它的真正原因
- **随想**：读书、生活，偶尔跑题
